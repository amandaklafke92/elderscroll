Tutorial video assets go here.

The app looks for these exact filenames (MP4, each under 30 seconds):

  lesson1-finger.mp4   Lesson 1, step 1 — the movement done with fingers on a phone
  lesson1-body.mp4     Lesson 1, step 2 — the same movement done with the body
  lesson2-finger.mp4   Lesson 2, step 1 — fingers on a phone
  lesson2-body.mp4     Lesson 2, step 2 — with the body

If a file is missing, the app shows a placeholder for that step and
automatically moves on, so the flow always works even with no videos here.
